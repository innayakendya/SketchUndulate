# SketchUndulate

SketchUndulate employs real-time vectorization and machine-learning algorithms to generate 3D models through iterative feedback loops and dynamic generators.

SketchUndulate is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/SketchUndulate.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
